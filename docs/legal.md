# Legal And Distribution Policy

This repository is for original project code, dependency patches, ReXGlue configuration, and contributor documentation only.

Users must provide their own legally obtained compatible game copy. Do not upload, request, link, or describe sources for unauthorized game files.

Do not commit ISO files, XEX/XEXP files, extracted title data, PE images, private binary dumps, save data from retail profiles, generated ReXGlue C++ output produced from a retail binary, keys, cracks, bypasses, or download links.

Each user runs ReXGlue codegen locally against their own legal extraction.
